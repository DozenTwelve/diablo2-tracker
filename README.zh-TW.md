# 暗黑破壞神 II 收藏追蹤

[English](README.md)

讀取你的 D2R 存檔資料夾，一次看清整個倉庫：每件暗金、套裝、符文之語和符文在哪個角色或哪一頁倉庫、有幾件，以及還缺哪些。

**網站：[d2r.diamonddoge.org](https://d2r.diamonddoge.org)**

![示範：新物品、搜尋、收藏、流派裝備、整理；再到 Steam Deck 上整理並備份、看套裝](docs/demo.gif)

存檔在你的瀏覽器裡用 WebAssembly 解析，不會上傳。網站沒有後端、沒有帳號，也不收集任何資料。

## 能做什麼

- **新物品。** 把新撿的東西放進共享倉庫的收件頁，馬上知道每件值不值得留：圖鑑還沒有、比你已有的那件好、還有流派用得上的重複品，或者是多餘的。只讀不寫，遊戲開著也能看。
- **圖鑑。** 暗金、套裝、符文之語、符文和咒符。
  - 暗金、套裝、符文之語和符文顯示已有幾件、總共幾件，以及缺哪些；套裝也列出套裝加成。
  - 符文之語還分頁列出你手上的散裝符文和空底材能做出什麼：已有、能做、只缺底材、差 1 個、差 2 個符文。拉蘇克或赫拉迪克方塊能打孔的底材也算在內，並標出方塊配方要用掉的符文和寶石。
  - 咒符頁列出你所有的咒符，分特大、大型、小型，暗金排在最前面。可以按用途篩選（技能、MF、生命、抗性、攻擊、屬性），屬性偏低的可以調暗或隱藏。
- **搜尋。** 用四種語言的任何一種搜尋物品，不管有沒有，都能看到每一件在哪裡。
- **角色。** 每個角色的身上、背包、儲物箱、方塊和腰帶，照遊戲裡的格子畫出來，滑過去有物品說明。圖鑑騾子會畫出空位，空格就是還缺的。
- **流派配裝。** 為主力號選一個流派（共 22 個熱門流派），點裝備欄就能看到推薦裝備你有哪些、放在哪。清單整理自 [Maxroll](https://maxroll.gg/d2/category/guides) 的攻略，附原文連結，可能過時，僅供參考。
- **整理。** 按固定規則把騾子和勾選的共享倉庫頁整理進編號騾子：
  - 暗金和套裝放進固定的「圖鑑」位置（`UW`、`UA`、`UJ`、`SET` 騾子），永遠放評分最好的那件，所以空位就是還沒有的；
  - 其餘依序是 `DUP`（流派用得上的重複品）、`RW`、`CHARM`、`LOWCHARM`、`JEWEL`、`LOWJEWEL`、`RING`（含護身符）、`MAG`（其他魔法和稀有物品）、`BASE`、`MISC`，以及 `TRASH`：所有職業的流派都用不上的多餘重複品。專家、舊版和經典模式的騾子名稱前面會加 `H`、`L` 或 `C`。
  - 咒符和珠寶不會進 `TRASH`：屬性偏低的放進 `LOWCHARM` 和 `LOWJEWEL`，多出來的暗金咒符和珠寶留在 `DUP`。重複品會標出比圖鑑那件好還是差。
  - 預覽會顯示整理後的結果，滑過去有物品說明。

  網頁會核對每件物品都剛好保留一份，再把整理後完整的存檔資料夾打包成 zip 給你下載；網頁版絕不會寫入你的存檔資料夾。
- **語言。** 繁體中文、簡體中文、英文、韓文，物品名稱用遊戲裡的官方譯名。

支援 PC 和 Steam Deck 上的單機（離線）角色，包括 Reign of the Warlock 資料片的存檔。戰網線上角色存在暴雪的伺服器上，讀不到；主機版不支援。

## 安全

所有東西都留在你的機器上：存檔由瀏覽器或 Deck 上的外掛讀取，不會上傳。只有 Deck 上的外掛會寫入存檔資料夾。每次寫入前：

- 先備份存檔資料夾裡的每個檔案；
- 確認 D2R 已經關閉（遊戲退出時會存檔，會蓋掉剛寫入的內容；遊戲執行中外掛會拒絕寫入）。

整理和換上配裝還會由外掛和網頁一起核對：

- 存檔和網頁讀到的一模一樣，逐位元組比對，所以中間遊戲存過的檔不會被蓋掉；
- 所有檔案加起來，沒有任何物品遺失或多出一份；
- 換上配裝時，每個主力號只改了配裝涉及的部分，其他主力號只少了被拿走的那幾件。

還原是把一份備份放回去取代目前的存檔，「清理 TRASH」則會連同物品刪除 `TRASH` 騾子：兩者都是刻意如此，而且寫入前同樣會先備份。

檔案先寫在目標旁邊，再改名蓋過去並讀回來核對；收物品的存檔先寫，交出物品的存檔後寫，所以寫到一半被打斷（斷電、Decky 被關掉）時，物品會同時在兩個存檔裡，而不會兩邊都沒有（騾子之間互相交換物品是例外）。不管怎樣，那次寫入的備份就是退路：還原它或關掉警告之前，外掛不會再寫入任何東西。

## 存檔在哪

- **Windows：** `%USERPROFILE%\Saved Games\Diablo II Resurrected`
- **Steam Deck：** 在遊戲的 Proton 資料夾裡，每台 Deck 的路徑都不一樣。

[docs/saves.md](docs/saves.md)（英文）寫了兩邊的詳細步驟、怎麼把存檔從 Deck 拷出來，以及整理好的存檔怎麼放回去：先退出遊戲、備份整個資料夾，再用 zip 裡的檔案取代資料夾裡的檔案。

## 用自己的規則整理

網頁只有一套固定的整理規則。想改規則，可以用 AI 程式助手（例如 Claude Code）執行 [organize-stash](.claude/skills/organize-stash/SKILL.md) skill。它會用 `scripts/organize.mjs` 帶你一步步來：先備份，再試跑並用白話說明結果，你同意後才寫入。

## Steam Deck 外掛

[decky/](decky/README.md)（英文）是一個 [Decky Loader](https://decky.xyz) 外掛：在遊戲模式的快捷選單裡打開收藏，直接讀這台 Deck 的存檔，物品圖示從你安裝的遊戲裡提取。在 Deck 上還能做到網頁做不到的事：

- **撿到物品時提醒。** 玩的時候，撿起暗金、套裝或符文，遊戲畫面上會跳出通知，告訴你圖鑑裡有沒有。可以在外掛面板裡關掉。
- **直接整理和清理 `TRASH`。** 「確認整理」會把整理好的存檔直接寫進存檔資料夾，而不是給你 zip，並刪除你勾選的清空角色。「清理 TRASH」先備份，再連同物品刪除 `TRASH` 騾子。它列出的 `TRASH` 物品滑過去有物品說明；把某件取消勾選、標成「不是垃圾」，以後整理就會把那一件（只有那一件）留在 `DUP`。
- **配裝。** 在主力號的頁面上，把它和傭兵身上穿的、以及背包裡的咒符存成一套有名字的配裝。頁面會顯示配裝裡每件現在在哪（身上、騾子、共享倉庫、另一個主力號）。按「換上」一次寫入、寫前核對：配件從騾子、共享倉庫或其他主力號拿過來（取消勾選的那件就留在原處），換下來的照整理的規則放進騾子。任務物品不會移動。配裝裡的物品算是要留的：不會進 `TRASH`，也不會被清理掉。
- **備份。** 每次寫入前都先備份存檔資料夾。整理頁列出所有備份，可以直接還原或刪除；會保留最近 10 份和最早那份，寫到一半被打斷的備份和舊版外掛做的備份也不會被自動刪掉。還原前也會先備份，所以還原也能撤銷。

外掛沒有上架 Decky 商店。安裝方法：Decky → 設定 → 一般 → 打開開發者模式，再到「開發者」→「從 URL 安裝外掛」，輸入

```
https://github.com/DozenTwelve/diablo2-tracker/releases/latest/download/d2r-collection-tracker.zip
```

（或從 [Releases](https://github.com/DozenTwelve/diablo2-tracker/releases) 下載 zip，用「從 ZIP 檔案安裝外掛」。）打開外掛，先按一次「從遊戲檔案提取物品圖標」（約一分鐘），再按「打開收藏」。要更新的話，從同一個網址再安裝一次。

## 開發

```bash
npm install
npm run dev
```

網站用 React 和 Vite。`src/lib/` 是邏輯（讀存檔、物品查詢、整理、翻譯），`src/components/` 是各個頁面。

- `wasm/` 包裝了 [d2s](https://github.com/ResurrectedTrader/d2s-rs)（MIT），用來讀寫 `.d2s` 角色和 `.d2i` 共享倉庫。編譯好的 `wasm/pkg/` 已提交，建置網站不需要 Rust。
- `src/data/*.json` 由遊戲本身的資料表和字串檔產生，從遊戲的 CASC 儲存裡提取（例如用 [casc-cli](https://github.com/ironsp4rk/casc-cli)）。原始遊戲檔案不會提交。
- 物品圖示從你自己的遊戲檔案轉成 `public/items/`，不進 git：本倉庫不含任何暴雪美術。沒有圖示時網站照樣能用，只是不顯示圖片。
- `src/data/builds.json` 是從 Maxroll 的「Gear Options」表格手動整理的。

各個指令的說明見[英文版 README](README.md#development)。[ROADMAP.md](ROADMAP.md)（英文）記錄了做過的計畫和原因。
